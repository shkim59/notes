## 기본 개념

| 개념 | 설명 | 예 |
|---|---|---|
| **객체** | 데이터(속성)와 그것을 처리하는 메서드(행동)를 묶은 독립 단위. 실제 세계의 개체를 모델링 | 자동차: 색상·모델·연식 / 시동 걸기·가속하기 |
| **클래스** | 객체의 설계도. 같은 클래스의 객체는 특성과 행동을 공유하지만 속성 값은 다를 수 있음 | 자동차 클래스 |
| **인스턴스** | 클래스를 기반으로 메모리에 할당된 실제 객체 | |
| **인터페이스** | 클래스가 구현해야 할 메서드 집합. 다중 상속 문제를 피하면서 느슨한 결합을 가능하게 함 | |
| **추상 클래스** | 직접 인스턴스화할 수 없고 상속으로만 사용. 추상 메서드(선언만 있는 메서드)를 가질 수 있음 | |
| **연관 관계** | 객체 간의 has-a 관계. 집합(Aggregation)과 합성(Composition)으로 나뉨 | |

## 4대 원칙

| 원칙 | 핵심 | 예 |
|---|---|---|
| **캡슐화** | 데이터와 메서드를 한 단위로 묶고 내부 구현을 숨김(정보 은닉). 접근 제어자로 외부 접근 제어 | 계좌 잔액은 입금/출금 메서드로만 변경 |
| **상속** | 기존 클래스의 속성·메서드를 재사용. 부모-자식 계층 관계 표현 | 차량 → 자동차, 트럭, 오토바이 |
| **다형성** | 같은 인터페이스로 여러 객체를 다룸. 오버라이딩(재정의), 오버로딩(같은 이름·다른 매개변수)으로 구현 | 동물 → 개·고양이·새가 `소리내기`를 각자 구현 |
| **추상화** | 핵심 개념만 추출해 단순화. 추상 클래스와 인터페이스로 구현. 필요한 정보만 노출 | 스마트폰 사용자는 아이콘만 누르면 됨 |

> 스프링 관점에서 본 다형성과 SOLID는 [스프링 기본](../spring/02-spring-core-basics.md) 참고.

## 장단점

| 장점 | 단점 |
|---|---|
| 모듈화로 유지보수 용이 | 함수형에 비해 성능 오버헤드가 있을 수 있음 |
| 코드 재사용성 | 잘못 설계하면 복잡하고 비효율적 |
| 대규모 프로젝트에 적합한 구조 | 상태 변경으로 인한 부수 효과 |
| 실제 세계를 직관적으로 모델링 | |

## 함수형 프로그래밍과의 관계

### 전통적 객체지향의 특성

1. **명령형** — "어떻게" 할지를 기술하고, 상태를 바꾸는 명령의 순서가 중요하다.
2. **가변성** — 메서드 호출로 객체 내부 상태가 바뀌는 것이 일반적이다.
3. **부수 효과** — 메서드가 객체 상태를 바꾸는 경우가 많다.
4. **순수 함수 부족** — 상태에 의존하거나 상태를 바꾸므로 "같은 입력 → 같은 출력, 부수 효과 없음"을 만족하지 못하는 경우가 많다.

### 현대적 객체지향

함수형의 원칙을 적극적으로 받아들인다.

1. **불변 객체** — 생성 후 상태가 바뀌지 않게 설계 (Java의 `String`, 불변 컬렉션)
2. **함수형 인터페이스** — Java 8+의 함수형 인터페이스, C#의 델리게이트 → [람다](./11-lambda.md)
3. **순수 메서드** — 객체 안에서도 상태를 바꾸지 않고 입력에만 의존하는 메서드
4. **선언적 스타일** — Java Stream API, C# LINQ → [Stream API](./10-stream-api.md)

### 하이브리드 예

```java
public final class Person {
    private final String name;
    private final int age;

    // 생성자로만 초기화, setter 없음 → 불변
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 상태를 바꾸지 않고 새 객체를 반환
    public Person withNewAge(int newAge) {
        return new Person(this.name, newAge);
    }

    public String getName() { return name; }
    public int getAge() { return age; }
}
```

→ 함수형 쪽 이야기는 [불변성](../fp/03-immutability.md), [액션·계산·데이터](../fp/02-action-calculation-data.md) 참고.
