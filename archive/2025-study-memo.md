# 2025 공부 키워드 메모

> 노션 '스터디 > 메모' 페이지. 스터디·면접 준비 중 적어둔 키워드 모음이라 원문 그대로 보관.

## 03

- 스프링에서는 추상화 대신 → 프록시 객체 → 빈
- 유스케이스 다이어그램: 연관관계, 포함관계, 확장관계, 부수적인 시나리오
- 호이스팅, 로더 (메모리에 적재되는 과정), 왜 메모리에 미리 저장할까
- **Exception**
  - 메모리 구조: compile → load → linking(외부 .jar) → execute
  - 로더: 메서드, 힙, 스택
  - 종류: 컴파일, 실행, 논리 / checked, unchecked / 스택 트레이스
- **스프링 동작 원리**
  - 프레임워크 → 규칙, 라이브러리 → 선택
  - 컨테이너가 객체 관리, 관점지향
  - ApplicationContext가 관리하는 경량 컨테이너
- 인덱스: 해시 인덱스, 역색인(텍스트별 ID 매핑 → 검색 최적화), BRIN(범위 검색)
- 소켓: 양방향 통신 프로토콜, 인터페이스 파일(프로토콜 요소로 추상화)
  - 윈도우 파일 핸들 / 리눅스 파일 디스크립터
  - 유저 모드에서 커널 모드로 진입 = 인터페이스 = 파일
- 데이터 흐름: OLTP(운영) → ODS(적재·임시 저장소) → DW(분석 대상 추출) → Data Mart(차원 분리, 팩트 테이블, 스타 스키마) → OLAP(데이터 마트를 활용한 대화식 다차원 분석)

## 04

- 컨테이너 네트워크: 컨테이너(경량, 표준화, 격리, 패키지), 서브넷 마스크
- 인터셉터와 필터의 차이
- TCP/IP
- 리덕스 3원칙: 단일 소스, 읽기 전용, 순수 함수로 변경
- 리액트 쿼리
- 컴파일러: 바이트 코드 유무의 차이

## 05

- `@Valid`(자바 표준) vs `@Validated`(스프링)
- OAuth 2.0: 권한 위임, Access Token, Refresh Token
- 멀티모듈, 모놀리식, DDD, 애그리거트, 롱 트랜잭션, 이벤트 드리븐
- REST API: API = 자원(기능) 교환 인터페이스, REST = 대표 상태 전달, REST 6원칙
- MobX, GPU vs CPU, ETL 파이프라인
- React Error Boundary: 전체 UI가 중단되는 것을 방지

## 06

- 스토리북: UI 컴포넌트 문서화 오픈소스
- Redis HA: sentinel, cluster(샤딩 + HA), 스냅샷
- 정규화: 1정규화(원자값), 2정규화(완전 함수 종속), 3정규화(이행 함수 종속 제거)
- OSI 7계층, DNS, TCP, TLS handshake
- 애자일, WBS(Work Breakdown Structure), PO/PM
- PMP 일정 관리: 활동 정의 → 순서 배열 → 기간 산정 → 일정 개발 → 일정 통제
- 코드 스플리팅: 초기 로딩 감소, lazy + Suspense
- multipart/form-data
- **Spring Batch**
  - 대용량 처리 (스케줄러와 다름)
  - 트랜잭션 관리, 재시작 지원, 청크 기반 처리, 메타데이터 관리
  - JobRepository, JobLauncher, Job, Step, 메타 테이블
  - 청크 사이즈 100~1000 권장, 실패 처리
- Jest
- 해시 함수: 항상 고정된 길이의 해시값(다이제스트) 출력
- Cursor rules: 코드 구조를 ask 모드로 물어본 다음 룰을 만들어 달라고 하면 좋음
- 디바운싱/스로틀링, 프록시, 쿠버네티스 아키텍처, SSR/CSR

## 07

- 제로 트러스트 보안 모델: 상시 감시, micro-segmentation(네트워크를 작은 단위로 나눠 구간별 보안 정책 적용)
- NAT: IP 주소 변환, 공인 IP 부족 문제 해결
- Docker
