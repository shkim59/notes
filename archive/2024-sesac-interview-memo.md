## OLTP vs DW vs OLAP

| | OLTP | DW (Data Warehouse) | OLAP |
|---|---|---|---|
| 정체 | 일반적인 트랜잭션 처리 시스템 | 오랜 기간 축적된 데이터를 통합한 데이터베이스 | DW의 데이터를 다양한 관점으로 추출·분석하는 기술·도구 |
| 특징 | 실시간 처리, CRUD | OLTP에서 데이터를 추출·변환·적재(**ETL**)해 의사 결정을 지원 | 대용량 데이터를 고속으로 다차원 분석. 의사 결정 지원 시스템의 하나 |
| 설계 | **정규화** | **비정규화** | |
| 예 | 주문, 결제 | 전사 통합 분석 DB | 사용자 소비 패턴, 연령대별 선호 상품 분석 |

> 트랜잭션: 여러 연산이 하나의 논리적 단위로 실행되는 것.
> 더 자세한 내용은 [DDIA — OLTP와 OLAP](../database/11-ddia-oltp-olap.md).

## AWS VPC

- **논리적으로 격리된 가상 네트워크**.
- 리소스를 분리된 가상 네트워크 안에 배치하고, 클라우드에서 완전히 격리된 네트워크를 직접 구성·제어할 수 있다.
- 보안을 위해 리소스 간 허용을 최소화하고, 그룹별로 네트워크를 쉽게 나누기 위해 사용한다.

## 제3정규형(3NF)

- 2NF를 만족하면서 **이행적 함수 종속**을 제거한 것.
- 즉, 기본 키가 아닌 일반 컬럼이 다른 일반 컬럼에 종속되는 관계를 없앤다. (A → B, B → C 일 때 A → C 제거)
