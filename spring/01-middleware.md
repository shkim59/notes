# 미들웨어

## 정의

- 애플리케이션과 운영체제 사이, 또는 클라이언트와 서버 사이에서 동작하면서 통신, 데이터 처리, 인증, 로깅 등 다양한 기능을 제공하는 소프트웨어

## 종류

- DB 커넥터
- 메시지 큐 (RabbitMQ, Kafka)
- WAS (Apache Tomcat)
- API Gateway
- Spring의 Filter, Interceptor, ControllerAdvice

## 왜 쓰는가

- **관심사의 분리**
  - 미들웨어가 없으면 애플리케이션이 운영체제의 복잡한 세부사항을 직접 처리하거나, 다른 애플리케이션과 통신하는 코드를 직접 작성해야 한다
  - 미들웨어가 이런 복잡성을 추상화하고 표준화된 인터페이스를 제공해, 개발자가 애플리케이션 로직에 집중할 수 있게 한다
- **결합도를 낮추고 응집도를 높인다** → 확장성과 유지보수성 향상
- **모듈화** → 재사용성
