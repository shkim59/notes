## 와일드카드

파일명 그룹을 패턴으로 지정하는 특수 문자.

| 와일드카드 | 매칭 |
|---|---|
| `*` | 0개 이상의 모든 문자 |
| `?` | 아무 문자 하나 |
| `[characters]` | 문자셋에 포함된 문자 하나 |
| `[!characters]` | 문자셋에 포함되지 않은 문자 하나 |
| `[[:class:]]` | 지정한 문자 클래스의 문자 하나 |

| 클래스 | 매칭 |
|---|---|
| `[:alnum:]` | 알파벳과 숫자 |
| `[:alpha:]` | 알파벳 |
| `[:digit:]` | 숫자 |
| `[:lower:]` / `[:upper:]` | 소문자 / 대문자 |

## mkdir, cp, mv

```shell
mkdir dir1 dir2 dir3          # 디렉토리 여러 개 생성

cp item1 item2                # item1을 item2로 복사
cp item1 item2 directory      # 여러 파일을 디렉토리로 복사

mv item1 item2                # 이동 또는 이름 변경 (원본은 사라짐)
```

| 옵션 | cp | mv | 설명 |
|---|---|---|---|
| `-a`, `--archive` | ✓ | | 소유자·권한 등 속성까지 모두 복사 |
| `-i`, `--interactive` | ✓ | ✓ | 덮어쓰기 전에 확인 |
| `-r`, `--recursive` | ✓ | | 디렉토리와 내용까지 복사 (디렉토리 복사 시 필수) |
| `-u`, `--update` | ✓ | ✓ | 대상에 없거나 더 최신인 파일만 |
| `-v`, `--verbose` | ✓ | ✓ | 완료 메시지 출력 |

## rm

> ⚠️ rm으로 지운 파일은 **되돌릴 수 없다.** 와일드카드와 함께 쓸 때는 **같은 패턴으로 `ls`를 먼저 실행**해서 대상을 확인한다.

| 옵션 | 설명 |
|---|---|
| `-i`, `--interactive` | 삭제 전 확인 |
| `-r`, `--recursive` | 디렉토리를 하위까지 재귀적으로 삭제 |
| `-f`, `--force` | 없는 파일은 조용히 무시, `-i`도 무시 |
| `-v`, `--verbose` | 완료 메시지 출력 |

## ln — 링크

```shell
ln file link        # 하드 링크
ln -s item link     # 심볼릭 링크
```

| | 하드 링크 | 심볼릭 링크 |
|---|---|---|
| 정체 | 같은 데이터(**아이노드**)를 가리키는 또 하나의 이름 | 대상의 경로를 담은 특수 파일 (윈도우 바로가기와 비슷) |
| 파일시스템 경계 | 같은 파티션 안에서만 | 제한 없음 |
| 디렉토리 | 불가 | 가능 |
| 원본 삭제 시 | 링크로 계속 접근 가능 (마지막 링크가 사라져야 데이터 삭제) | 링크가 아무것도 가리키지 않게 됨 |

- 모든 파일은 기본적으로 하드 링크 하나를 가진다. `ls -i`로 아이노드 번호를 확인할 수 있다.
- 심볼릭 링크를 편집하면 원본이 바뀌고, 링크를 지우면 링크만 사라진다.
