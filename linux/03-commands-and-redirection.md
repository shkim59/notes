## 명령어의 네 종류

1. 실행 프로그램 (`/usr/bin`의 파일들)
2. 쉘 내장 명령어
3. 쉘 함수
4. 별칭(alias)

## 명령어 확인과 도움말

| 명령어 | 설명 |
|---|---|
| `type command` | 명령어의 종류 확인 |
| `which ls` | 실행 프로그램의 위치 (`/bin/ls`) |
| `help cd` | 쉘 내장 명령어 도움말 |
| `mkdir --help` | 프로그램 자체 도움말 옵션 |
| `man program` | 매뉴얼 페이지 (less로 표시되므로 less 키 사용 가능) |
| `apropos floppy` | 검색어와 일치하는 man 페이지 목록 |
| `whatis ls` | man 페이지의 한 줄 설명 |
| `info` | man의 대안인 info 페이지 |

| man 섹션 | 내용 |
|---|---|
| 1 | 사용자 명령어 |
| 2 | 커널 시스템 콜 |
| 3 | C 라이브러리 |
| 4 | 장치 노드·드라이버 같은 특수 파일 |
| 5 | 파일 포맷 |
| 6 | 게임 |
| 7 | 기타 |
| 8 | 시스템 관리 명령어 |

## alias

```shell
alias foo='cd /usr; ls; cd -'   # 별칭 만들기
alias                            # 등록된 별칭 보기
unalias foo                      # 삭제
```

> 커맨드라인에서 만든 별칭은 쉘 세션이 끝나면 사라진다. 유지하려면 `~/.bashrc`에 적는다.

## 리다이렉션

- 프로그램 출력은 **결과(표준 출력)** 와 **상태·오류 메시지(표준 오류)** 두 가지다. 둘 다 기본적으로 화면으로 간다.
- 표준 입력은 기본적으로 키보드다.
- 쉘은 내부적으로 표준 입력·출력·오류를 **파일 디스크립터 0, 1, 2**로 다룬다.

| 문법 | 동작 |
|---|---|
| `cmd > file` | 표준 출력을 파일로 (덮어쓰기) |
| `cmd >> file` | 표준 출력을 파일 끝에 이어 쓰기 |
| `> file` | 파일을 비우거나 빈 파일 생성 |
| `cmd 2> file` | 표준 오류를 파일로 |
| `cmd > file 2>&1` | 출력과 오류를 한 파일로 (예전 방식). **순서 중요** — 출력 재지정이 먼저 |
| `cmd &> file` | 출력과 오류를 한 파일로 (최신 bash) |
| `cmd 2> /dev/null` | 오류 버리기. `/dev/null`은 입력을 받고 아무것도 하지 않는 **비트 버킷** |
| `cmd < file` | 표준 입력을 파일에서 |

```shell
ls -l /usr/bin > ls-output.txt
ls -l /bin/usr > ls-output.txt      # 없는 디렉토리 → 오류는 표준 오류라 화면에 뜨고 파일은 비어 있음
ls -l /bin/usr 2> ls-error.txt
```

### cat

파일을 읽어 표준 출력으로 복사한다. 페이지 구분 없이 출력해서 짧은 파일을 보거나 **파일을 합칠 때** 쓴다.

```shell
cat movie.mpeg.0* > movie.mpeg     # 와일드카드는 항상 정렬된 순서로 확장됨
cat > lazy_dog.txt                 # 키보드 입력을 파일로, CTRL+D(EOF)로 종료
cat < lazy_dog.txt                 # 표준 입력 재지정
```

## 파이프라인과 필터

`|`로 한 명령어의 표준 출력을 다음 명령어의 표준 입력에 연결한다. 여러 개를 이어 복잡한 처리를 할 수 있다.

```shell
ls -l /usr/bin | less
ls /bin /usr/bin | sort | uniq | grep zip
```

| 명령어 | 설명 |
|---|---|
| `sort` | 정렬 |
| `uniq` | 정렬된 입력에서 중복 제거. `-d`는 중복된 것만 표시 |
| `wc` | 줄 수, 단어 수, 바이트 수. `-l`은 줄 수만 |
| `grep` | 패턴과 일치하는 줄 출력. `-i` 대소문자 무시, `-v` 일치하지 않는 줄 |
| `head` / `tail` | 앞 / 뒤 부분 출력. `-n 5`로 줄 수 지정 |
| `tail -f` | 파일에 추가되는 내용을 실시간으로 출력 (**로그 확인**에 유용), CTRL+C로 종료 |
| `tee` | 표준 입력을 표준 출력과 파일에 **동시에** 출력 |

```shell
tail -f /var/log/messages
ls -l /usr/bin | tee ls.txt | grep zip
```
