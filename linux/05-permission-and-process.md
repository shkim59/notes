## 사용자와 그룹

- 유닉스 보안 모델에서 사용자는 파일·디렉토리를 **소유**하고 접근을 제어한다.
- 사용자는 하나 이상의 **그룹**에 속할 수 있고, 소유자는 그룹이나 기타 사용자에게 권한 일부를 줄 수 있다.
- 계정을 만들면 **uid**(사용자 ID), 사용자 이름, **주 그룹 gid**가 할당된다.

```shell
$ id
uid=1000(user) gid=1000(user) groups=...
```

| 파일 | 내용 |
|---|---|
| `/etc/passwd` | 사용자 계정 (이름, uid, gid, 홈 디렉토리, 로그인 쉘) |
| `/etc/group` | 그룹 정의 |
| `/etc/shadow` | 비밀번호 정보 |

## 파일 속성 읽기

`ls -l`의 첫 10글자.

```
-  rw-  rw-  r--
│   │    │    └ 기타 사용자
│   │    └ 그룹
│   └ 소유자
└ 파일 종류
```

| 종류 | 의미 |
|---|---|
| `-` | 일반 파일 |
| `d` | 디렉토리 |
| `l` | 심볼릭 링크 (권한은 항상 `rwxrwxrwx`인 더미 값) |
| `c` | 문자 특수 파일 (터미널처럼 바이트 스트림을 다루는 장치) |
| `b` | 블록 특수 파일 (디스크처럼 블록 단위로 다루는 장치) |

| 권한 | 파일 | 디렉토리 |
|---|---|---|
| `r` | 열기·읽기 | 목록 보기 (`x`도 있어야 함) |
| `w` | 쓰기·내용 비우기. 이름 변경·삭제는 **디렉토리 권한**이 결정 | 안에서 파일 생성·삭제·이름 변경 (`x`도 있어야 함) |
| `x` | 실행. 스크립트는 `r`도 있어야 실행 가능 | 디렉토리에 들어가기(`cd`) |

## chmod — 권한 변경

소유자나 슈퍼유저만 바꿀 수 있다.

### 8진수 표기

| 8진수 | 2진수 | 권한 |
|---|---|---|
| 7 | 111 | `rwx` |
| 6 | 110 | `rw-` |
| 5 | 101 | `r-x` |
| 4 | 100 | `r--` |
| 0 | 000 | `---` |

```shell
$ chmod 600 foo.txt
$ ls -l foo.txt
-rw------- 1 ...
```

자주 쓰는 값: 7, 6, 5, 4, 0 (예: `755` 실행 파일·디렉토리, `644` 일반 파일, `600` 개인 파일)

### 기호 표기

`대상` + `연산` + `권한`

| 대상 | | 연산 | |
|---|---|---|---|
| `u` | 소유자 | `+` | 추가 |
| `g` | 그룹 | `-` | 제거 |
| `o` | 기타 사용자 | `=` | 지정한 권한만 (나머지 해제) |
| `a` | 전체 (생략 시 기본값) | | |

| 예 | 의미 |
|---|---|
| `u+x` | 소유자에게 실행 추가 |
| `+x` | 모두에게 실행 추가 |
| `o-rw` | 기타 사용자의 읽기·쓰기 제거 |
| `go=rw` | 그룹·기타는 읽기·쓰기만 (기존 실행 권한은 해제) |
| `u+x,go=rw` | 여러 개는 쉼표로 |

## umask — 기본 권한

- 파일을 만들 때 **빼 버릴 권한 비트**를 8진수 마스크로 지정한다. 기본값은 보통 `0002` 또는 `0022`.
- 마스크에서 1인 비트의 권한이 해제된다.

| | 소유자 | 그룹 | 기타 |
|---|---|---|---|
| 원래 파일 모드 | `rw-` | `rw-` | `rw-` |
| 마스크 `002` | `000` | `000` | `010` |
| 결과 | `rw-` | `rw-` | `r--` |

## 프로세스

- 부팅 시 커널이 **init**을 실행하고(요즘 배포판은 systemd), init이 시스템 서비스를 시작한다.
- 서비스는 사용자 인터페이스 없이 백그라운드에서 도는 **데몬**으로 구현된다. 로그인하지 않아도 동작한다.
- 프로그램은 다른 프로그램을 실행할 수 있다 → **부모 프로세스가 자식 프로세스를 생성**한다.
- 각 프로세스는 **PID**를 받는다. 오름차순으로 할당되어 init은 항상 PID 1이다.
- 프로세스도 파일처럼 소유자와 사용자 ID를 가진다.

### ps

```shell
$ ps          # 현재 터미널 세션의 프로세스
  PID TTY          TIME CMD
 1111 pts/1    00:00:00 bash

$ ps x        # 터미널과 무관하게 내 모든 프로세스 (TTY의 ?는 제어 터미널 없음)
$ ps aux      # 모든 사용자의 프로세스
```

| 헤더 | 의미 |
|---|---|
| TTY | 제어 터미널 |
| TIME | CPU 사용 시간 |
| STAT | 프로세스 상태 |
| USER | 소유자 |
| %CPU / %MEM | CPU / 메모리 사용률 |
| VSZ | 가상 메모리 크기 |
| RSS | 실제 사용 중인 물리 메모리(KB) |
| START | 시작 시각 (24시간이 넘으면 날짜) |

| STAT | 의미 |
|---|---|
| `R` | 실행 중 또는 실행 대기 |
| `S` | 수면 — 키 입력, 네트워크 패킷 같은 이벤트 대기 |
| `D` | 인터럽트 불가 수면 — 주로 디스크 I/O 대기 |
| `T` | 정지됨 (일시 정지 신호를 받은 상태) |
| `Z` | 좀비 — 종료됐지만 부모가 정리하지 않은 자식 프로세스 |
| `<` | 높은 우선순위 (nice 값이 낮음) |
| `N` | 낮은 우선순위 |

> 운영체제 관점의 프로세스는 [프로세스](../os/03-process.md), [프로세스 관리](../os/04-process-management.md) 참고.
