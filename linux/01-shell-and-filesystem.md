## 쉘

| 용어 | 설명 |
|---|---|
| **쉘** | 키보드로 입력한 명령어를 운영체제에 전달해 실행하게 하는 프로그램 (리눅스 기본은 bash) |
| **터미널 에뮬레이터** | GUI 환경에서 쉘과 작업할 수 있게 해주는 프로그램 |
| **프롬프트** | 쉘이 입력을 받을 준비가 되면 나타남. 끝이 `$`가 아니라 **`#`이면 슈퍼유저 권한** |
| **명령어 히스토리** | 대부분의 배포판은 최근 명령어 500개를 기억함 |

```shell
[user@linux ~]$ date    # 현재 날짜와 시간
[user@linux ~]$ cal     # 이번 달 달력
[user@linux ~]$ df      # 디스크 사용량과 남은 용량
[user@linux ~]$ free    # 메모리 사용 현황
```

## 파일시스템

- 유닉스형 OS도 **계층적 트리 구조**로 파일을 구성하고, 최상위를 **루트 디렉토리(`/`)** 라고 한다.
- 윈도우처럼 저장 장치마다 트리가 따로 있지 않고, 장치 수와 상관없이 **하나의 파일시스템**으로 관리한다.
- 처음 로그인하면 홈 디렉토리가 현재 작업 디렉토리다.

### 기본 명령어

| 명령어 | 설명 |
|---|---|
| `pwd` | 현재 작업 디렉토리 출력 (Print Working Directory) |
| `ls` | 디렉토리 목록 |
| `cd` | 작업 디렉토리 변경 |

### 절대 경로 vs 상대 경로

| | 시작점 | 예 (`/usr/bin`에서) |
|---|---|---|
| 절대 경로 | 루트 `/` | `cd /usr` |
| 상대 경로 | 현재 디렉토리. `.`(현재), `..`(상위) | `cd ..` |

```shell
[me@linux usr]$ cd /usr/bin   # 절대 경로
[me@linux usr]$ cd ./bin      # 상대 경로
[me@linux usr]$ cd bin        # 대부분 ./ 생략 가능
```

| 단축 표현 | 이동 위치 |
|---|---|
| `cd` | 내 홈 디렉토리 |
| `cd -` | 이전 작업 디렉토리 |
| `cd ~username` | username의 홈 디렉토리 |

### 파일 이름 규칙

- `.`으로 시작하는 파일은 **숨김 파일**이다 (`ls -a`로 보임).
- 파일명과 명령어는 **대소문자를 구분**한다.
- **확장자 개념이 없다.** (프로그램에 따라 확장자를 참고하긴 함)
- 공백이 들어간 이름도 되지만 권장하지 않는다. `_`로 구분한다.

## 시스템 살펴보기

### ls

```shell
ls /usr        # 다른 디렉토리 목록
ls ~ /usr      # 여러 디렉토리를 한 번에
```

옵션은 `-`(짧은 옵션) 또는 `--`(긴 옵션)로 준다.

| 옵션 | 긴 옵션 | 설명 |
|---|---|---|
| `-a` | `--all` | 숨김 파일 포함 |
| `-d` | `--directory` | `-l`과 함께 쓰면 디렉토리 내용이 아니라 디렉토리 자체 정보 |
| `-F` | `--classify` | 종류 표시 문자 추가 (디렉토리 끝에 `/`) |
| `-h` | `--human-readable` | `-l`과 함께 크기를 읽기 쉬운 단위로 |
| `-l` | | 긴 형식(long format)으로 출력 |
| `-r` | `--reverse` | 역순 정렬 |
| `-S` | | 파일 크기순 정렬 |
| `-t` | | 수정 시간순 정렬 |

### 긴 형식 읽기

```shell
-rw-r--r-- 1 root root 23242 2024-01-17 oo-cd-cover.odf
```

| 항목 | 의미 |
|---|---|
| `-rw-r--r--` | 파일 종류와 권한 → [퍼미션](./05-permission-and-process.md) |
| `1` | 하드 링크 수 |
| `root` | 소유자 |
| `root` | 소유 그룹 |
| `23242` | 크기(바이트) |
| `2024-01-17` | 마지막 수정 날짜 |
| `oo-cd-cover.odf` | 파일명 |

### file, less

```shell
file filename       # 파일 종류 확인
less /etc/passwd    # 텍스트 파일 보기
```

| less 키 | 동작 |
|---|---|
| `b` / Page Up | 한 페이지 위 |
| Space / Page Down | 한 페이지 아래 |
| ↑ / ↓ | 한 줄 위·아래 |
| `G` / `g` | 맨 끝 / 맨 처음 |
| `/문자열` | 아래 방향으로 검색, `n`으로 다음 결과 |
| `h` | 도움말 |
| `q` | 종료 |
