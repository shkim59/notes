## 부수 효과(Side Effect)

앱이 동작하려면 반드시 실행되어야 하지만, **현재 컴포넌트의 렌더링 과정에 직접 영향을 주지 않는 작업**.

React 컴포넌트의 주된 역할은 JSX를 반환해 UI를 렌더링하는 것이고, 부수 효과는 그 과정과 직접 관련이 없는 작업이다.

- **렌더링과 독립적**: 화면의 UI를 직접 바꾸지 않는다.
- **비동기 작업**: 서버에서 데이터 가져오기처럼 미래의 어느 시점에 끝나는 작업을 포함한다.
- 주로 `useEffect` 같은 훅에서 처리한다.

## 문제: 상태 업데이트로 인한 무한 루프

상태를 업데이트하면 React는 **컴포넌트 함수를 재실행**한다. 컴포넌트 본문에서 데이터를 가져와 상태를 업데이트하면 무한 루프가 된다.

```jsx
const [fetchData, setFetchData] = useState();

const response = fetch();          // 서버에서 데이터를 가져온다고 가정
setFetchData(response.data);       // 상태 업데이트 → 컴포넌트 재실행 → 다시 fetch → ...
```

## useEffect

- **컴포넌트가 렌더링된 후 실행**되는 작업을 다루는 훅.
- 이펙트 함수는 즉시 실행되지 않고 렌더링이 끝난 뒤 실행된다.
- 두 번째 인수인 **의존성 배열**로 재실행 시점을 제어한다.

```jsx
const [fetchData, setFetchData] = useState();

useEffect(() => {
  const response = fetch();
  setFetchData(response.data);
}, []); // 빈 배열 → 첫 렌더링 후 한 번만 실행
```

| 의존성 배열 | 실행 시점 |
|---|---|
| `[]` | 첫 렌더링 후 한 번 |
| `[a, b]` | 첫 렌더링 후 + `a`나 `b`가 바뀔 때마다 |
| 생략 | 매 렌더링 후 |

### 용도

- 렌더링 이후 실행되어야 하는 작업 (비동기 요청, 사용자 위치 정보 가져오기 등)
- DOM과의 동기화
- **clean up**: 이펙트 함수가 반환하는 함수로 정리 작업(구독 해제, 타이머 제거 등)을 한다.

### 규칙

- 반드시 컴포넌트 함수의 **최상위(루트) 수준**에서 호출한다.
- 조건문, 중첩 함수 안에서는 쓸 수 없다 → [Hook 규칙](./04-hooks.md)
