## Git

- 가장 널리 쓰이는 **버전 관리 시스템(VCS)**. 파일의 변경 내역을 시간 순으로 추적·관리한다.
- 무료 오픈 소스이며 **분산 버전 관리 시스템**이다. 작은 프로젝트부터 대규모 프로젝트까지 효율적으로 다루고, 빠르고 저장 공간을 적게 차지한다. Subversion, CVS 같은 이전 도구보다 기능이 뛰어나다.
- 사실상 표준이다. 2018년 Stack Overflow 설문에서 약 90%가 사용했고, 이후 95%를 넘기면서 설문 항목에서 빠질 정도가 되었다.

### VCS의 역할

- 파일의 변경을 기록하고 필요하면 특정 시점으로 되돌린다.
- 변경 사항을 비교한다.
- 여러 작업자와 변경을 공유한다.

## Git vs GitHub

| | Git | GitHub |
|---|---|---|
| 정체 | 버전 관리 **소프트웨어** | Git 저장소를 호스팅하는 **웹 서비스** |
| 실행 위치 | 내 컴퓨터 (로컬) | 클라우드 |
| 인터넷·계정 | 필요 없음 | 필요 |
| 역할 | 로컬 프로젝트 히스토리를 체크포인트처럼 관리 | 원격 저장소로 공유·협업 (내려받아 수정하고 다시 올리기) |

- Git은 GitHub 없이 쓸 수 있지만, GitHub을 쓰려면 Git을 알아야 한다.
