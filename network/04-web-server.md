# 웹 서버

- 소프트웨어와 장비
- HTTP 요청을 처리하고 응답 제공
- HTTP 및 관련된 TCP 처리를 구현
- HTTP 프로토콜 구현, 웹 리소스 관리, 웹 서버 관리 기능
- TCP 커넥션 관리 책임을 운영체제와 나눠 가짐

## 하는 일

1. 커넥션 맺기
2. 요청 받기
3. 요청 처리
4. 리소스 접근
5. 응답 생성
6. 응답 전송
7. 트랜잭션 로그

## 커넥션 맺기

- TCP 커넥션에서 IP 주소를 추출하여 클라이언트를 확인
- 새 커넥션을 커넥션 목록에 추가
- 커넥션을 거절하거나 닫을 수 있음

## 호스트명 식별

- 역방향 DNS를 사용해 클라이언트의 IP 주소를 클라이언트의 호스트명으로 변환
- 호스트명 룩업은 시간이 다소 소요될 수 있음

## ident

- 프로토콜
- 서버에게 어떤 사용자 이름이 HTTP 커넥션을 초기화했는지 찾아낼 수 있게 해줌
- 클라이언트가 ident를 지원하면 ident 결과를 위해 TCP 113 포트를 LISTEN 한다

## 요청 메시지 수신

- 커넥션이 도착하면 데이터를 읽고 파싱해 요청 메시지를 구성
  - 요청 메서드, 리소스의 식별자(URI), 버전 번호를 찾는다
  - 메시지 헤더들을 읽는다.
  - 요청 본문이 있으면 읽는다.
