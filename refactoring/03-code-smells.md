## 기이한 이름 (Mysterious Name)

- 코드를 단순 명료하게 만드는 가장 중요한 요소는 **이름**이다.
- 함수, 모듈, 변수, 클래스 모두 **이름만 보고 무엇을 하는지, 어떻게 쓰는지** 알 수 있어야 한다.
- 관련 기법: 함수 선언 바꾸기(6.5), 변수 이름 바꾸기(6.7), 필드 이름 바꾸기(9.2)

## 중복 코드 (Duplicated Code)

- 같은 코드 구조가 반복되면 하나로 합친다. 단, 차이점을 주의 깊게 봐야 한다.

| 상황 | 기법 |
|---|---|
| 같은 코드가 여러 곳에 | 함수 추출하기(6.1) |
| 비슷하지만 완전히 같지 않음 | 문장 슬라이드하기(8.6)로 비슷한 부분을 모은 뒤 추출 |
| 같은 부모의 서브클래스들에 중복 | 메서드 올리기(12.1) |

## 긴 함수 (Long Function)

- 짧은 함수들에 작업을 **위임**하는 방식으로 작성한다.
- 간접 호출의 효과: 코드를 이해하고, 공유하고, 선택하기 쉬워진다.
- 짧은 함수로 구성된 코드를 쉽게 읽으려면 **이름을 잘 지어야** 한다.
- **주석을 달아야 할 만한 부분은 함수로 만든다.**
- 함수 이름은 **동작 방식이 아니라 의도**가 드러나게 짓는다.
